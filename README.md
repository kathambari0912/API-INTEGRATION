I learned HTML, CSS, and JavaScript from online video tutorials and built this as my first project.
The app has three files — index.html, style.css, and script.js — each handling structure, design, and logic separately.
I styled the app with a gradient background, rounded card, and hover effect using basic CSS properties I learned.
The app fetches live weather data from the OpenWeatherMap API and shows the temperature, description, and wind speed for any city you search.
I used jQuery to handle button clicks and update the page, and Moment.js to show the current date and time.
The weather icon is an image I downloaded from the browser and saved in my project folder, then linked it in the HTML file.
This project helped me understand how to use an API, handle live data, and connect everything together into a working web app.
